# S3: Core flow UI

Goal: Home, Check-in, Ideas, Watch, feedback, and support, usable on a phone, with every async state handled.

**Files owned (under ``):** `src/pages/index.tsx`, `src/pages/(app)/home.tsx`, `src/pages/(app)/(protected)/checkin.tsx`, `src/components/{AppFooter,SupportCard,ChoiceGroup,YouTubePlayer}.tsx`, `src/components/checkin/*`, `src/lib/{support,youtube,recommend-client,format}.ts`, `src/contract.ts` (added `suggestionId`), `src/constants.ts`, `src/nav.ts`, `src/seo.ts`, `tests/checkin.spec.ts`.

**In scope (enumerated):**
1. Check-in form: mood, energy, minutes, optional goal, optional note with a visible privacy line.
2. Ideas view: companion reply, 2-3 cards (length, channel, reason), Watch / Not this one, "None of these fit?" with reason chips, two retries then a calm stop.
3. Watch: YouTube IFrame player (no autoplay, no overlays, 200px minimum), inline fallback for error 100/101/150 with Open on YouTube, ended event replaces the player with our feedback card, "I'm done" button.
4. Feedback: "Was this useful?" yes / a little / not really. Never asks about mood change.
5. Response states: ok, no_video, support, nothing_fits, capped, error (local retry, no page reload).
6. Support: static card (988 call/text/chat, Crisis Text Line 741741, 911, findahelpline.com) on the crisis path and from a footer link on every screen.
7. Footer disclaimer on every screen; landing page and home rewritten; "calm" theme default.

**Out of scope (later slices):** Save button and Saved page (S4), preferences and history (S5), YouTube-dependent verification, deploy.

**Acceptance (automated):** `tsc`, `eslint`, 76 unit tests, 19 browser tests (8 new in `tests/checkin.spec.ts`, 11 from the scaffold), all green on 2026-09-30.
**Acceptance (manual, Elena):** play a real video; find an embedding-disabled video; read the support card wording; use it on your phone.

**What these checks do NOT prove:** the recommend action is mocked in the browser tests, and `window.YT` is faked, so they prove the UI handles each state but not that real videos play, what YouTube shows after a video ends, or that the server returns real data. Screenshots were reviewed at 1100px and 375px for the form, ideas, home, and support dialog only; the Watch screen with a real player has not been looked at.
