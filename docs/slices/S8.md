# S8: Plans from your calendar, "Talk about this", and event reflections (2026-10-02)

**Elena's direction:** use upcoming plans as context for support and reflection. Compact list of today's or upcoming plans (not an agenda, not scheduling). Core flow: pick a calendar event or type a plan by hand → optionally talk with the bunny about how you feel → the bunny responds supportively and offers a small activity only when useful → come back after and write a reflection → reflections are saved and reachable later (in the existing Journal). Home gets the big bunny back at the top, fixed, in addition to the floating bunny.

**What changes from S7/Calendar-fit (privacy):** until now event titles never left the check-in button. Now, only when the person presses **Talk about this**, the plan's title and time go into the conversation (so the AI sees them, and they are saved with the chat unless "Don't save"). Reflections save the event title and time with the person's text in their own Journal. Titles shown on Home live only in the page, never stored by us unless the person chooses one of those two actions. The privacy page says so.

**Build order (each reviewable):**
- **8a Plans and Home.** `src/plans/plan.ts` (pure: window today to end of tomorrow, status upcoming/now/done, title cleanup, manual plan), `use-plans` (fetches once when asked; once per session on its own only if the person has used it before; never stores titles), `PlansCard` on Home, a hand-typed plan form, big fixed bunny back at the top of Home (read-only words, a "Say something" button that focuses the floating text box; no second text box).
- **8b Talk about this.** Starts a new conversation whose first bunny message is a fixed line ("You have X at 3:30 PM. How are you feeling about it?"), no model call, so nothing is assumed. The model sees that line as part of the thread, so no new server parameter. Prompt gains a short rule: do not assume the plan is stressful or exciting; follow the person. The reply may carry `offer: true` only when a small activity would plainly help; the UI then shows an optional "Find a small idea" link to Check-in with the time prefilled to the minutes until the plan. Never forced.
- **8c Reflections in the Journal.** `journalEntries` gains `kind`, `eventId`, `eventTitle`, `eventStart`. One reflection per event (writing again edits it). One gentle prompt at a time ("How did it go?" / "Anything you'd like to remember?" / "What felt good or difficult?"), skip or switch, optional feeling chips, free text. Journal shows reflections with Edit and Delete. Crisis words in a reflection show the support card (no model involved).

**Not changing:** the check-in "Use my calendar" button (times only), the floating bunny, the Messages page, the safety layers.

**What the checks will not prove:** the real Google response shape (confirmed only after a real connected call), the model's tone when plans are mentioned, that a real person finds the prompts kind, billing of calendar calls to users.
